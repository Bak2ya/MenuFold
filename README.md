# MenuFold

제가 잘 쓰는 메뉴바 기능을 하나로 합치고 싶었어요.

네트워크 미터, 잠자기 방지, 빠른 실행, 메뉴바 접기 기능을 한 곳에 모은 macOS 메뉴바 앱입니다.

Bak2YA가 ChatGPT와 함께 만들었어요

## 기능

- 네트워크 속도 표시
- Mac 잠자기 방지
- 앱, 파일, 폴더, 웹사이트 등의 빠른 실행 목록 생성
- 메뉴바 항목 관리
- 한국어 / 일본어 / 영어 / 스페인어 지원
- 다크 모드 / 라이트 모드
- Apple Silicon / Intel Mac 지원

## 사용 방법

- **MenuFold 좌클릭**  
  빠른 실행과 잠자기 방지 기능을 사용할 수 있습니다.

- **MenuFold 우클릭**  
  메뉴바 관리 기능을 사용할 수 있습니다.  
  메뉴바를 나누는 아이콘을 우클릭하면 접어둔 메뉴바 영역을 펼친 상태로 고정할 수 있습니다.

- **설정**  
  네트워크 미터가 필요하지 않은 경우 설정에서 끌 수 있습니다.

# English

MenuFold is a macOS menu bar utility that brings together a network meter,
sleep prevention, Quick Launch, and menu bar folding in one place.

### Features

- Network speed meter
- Sleep prevention
- Quick Launch for apps, files, folders, and websites
- Menu bar item management
- Korean / Japanese / English / Spanish support
- Light / Dark appearance
- Apple Silicon and Intel Mac support

MenuFold runs entirely from the macOS menu bar without a Dock icon.

### Privacy

MenuFold does not collect personal data.
